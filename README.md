* Python 3
* Pytest
* Requests
* Allure Report
* Faker

## Объект тестирования

Сервис заказа самокатов.

**Base URL:**

```text
https://qa-scooter.praktikum-services.ru
```

### Используемые эндпоинты

| Метод  | Endpoint              | Описание                 |
| ------ | --------------------- | ------------------------ |
| POST   | /api/v1/courier       | Создание курьера         |
| POST   | /api/v1/courier/login | Авторизация курьера      |
| DELETE | /api/v1/courier/{id}  | Удаление курьера         |
| POST   | /api/v1/orders        | Создание заказа          |
| GET    | /api/v1/orders        | Получение списка заказов |

## Покрытие тестами

### Создание курьера

Проверяется:

* успешное создание курьера;
* создание курьера с пустым логином;
* создание курьера с пустым паролем;
* создание курьера с пустым именем;
* повторное создание курьера с уже существующим логином.

### Авторизация курьера

Проверяется:

* успешная авторизация существующего курьера;
* авторизация с пустым логином;
* авторизация с пустым паролем;
* авторизация с существующим логином и неправильным паролем;
* авторизация с существующим паролем и неправильным логином;
* авторизация несуществующего пользователя.

### Создание заказа

Проверяется создание заказа со всеми доступными вариантами параметра `color`.

### Получение списка заказов

Проверяется:

* успешное получение списка заказов;
* корректный статус-код ответа;
* наличие списка заказов в ответе.

## Тестовые данные

Для генерации уникальных данных используется библиотека **Faker**.

Автоматически генерируются:

* имя;
* фамилия;
* логин;
* пароль;
* адрес;
* телефон;
* дата доставки заказа и др.

Это позволяет избежать конфликтов данных между запусками тестов.

## Установка зависимостей

Клонировать репозиторий:

```bash
git clone <repository_url>
```

Перейти в директорию проекта:

```bash
cd YandexPracticum_Sprint_7
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

---

## Запуск тестов

Запуск всех тестов:

```bash
pytest
```

Запуск с подробным выводом:

```bash
pytest -v
```

Запуск отдельного тестового файла:

```bash
pytest tests/test_create_courier.py -v
```

---

## Генерация Allure-отчёта

Сбор результатов выполнения тестов:

```bash
pytest --alluredir=allure_results
```

Формирование и открытие отчёта:

```bash
allure serve allure_results
```
